# Интеграция `tram_final (2).zip`

Модель из нового архива прогнозирует **успешные валидации за час по всему маршруту**. Это не занятость вагона и не прогноз по остановке. Исходный итоговый файл `outputs/submission_final.csv` скопирован без изменений в `backend/data/tram_final_submission.csv` (SHA-256 `05d73ac9bff3364cd1df815c3a3bd5d4a25cdcd2d2711db9e7a5ae7e9778d901`). API загружает его один раз при запуске и выдаёт маршрутный ряд без округления или пересчёта. Месячный экран суммирует 24 часовых значения для каждого дня.

Архив содержит 15 бустеров объёма, один бустер профиля, исходники конвейера и предрассчитанные выходы. Для повторного инференса LightGBM нужны исторические `labels/labels_day_train.csv`, `labels/labels_day_test.csv` и `test_submission.csv`: они не входят в архив. Итоговый прогноз к тому же включает математический ансамбль, сезонную поправку и обработку 1 ноября. Поэтому сервер использует **проверенный конечный результат всего конвейера**, а не выдаёт один бустер за финальную модель. Новые даты таким способом не рассчитываются.

Покрытие: 01.11–31.12.2025, маршруты 1, 7, 11, 12, 17, 25, 26, 28, 50. В исходном CSV есть маршрут 5, но он исключён из проекта по требованию команды: для него нет обучающей цели в этой версии сайта. В интерфейсе доступны день и месяц; год показан, но недоступен, так как в архиве нет полного года. Для `GET /forecast` без `stop_id` и `direction_id` модель возвращает `value_unit=validations`, `aggregation=sum`, `is_mock=false`, `model_version=tram-final-2025-0.90461`. Запросы за пределами периода и по маршруту 5 возвращают 503.

`GET /forecast/map` по остановкам остаётся техническим источником точек карты и сохраняет `is_mock=true`, `value_unit=demo_index`; его численные значения интерфейс не показывает. Остановки представлены по имени и месту, линии окрашены по маршруту. Рейтинг сети, сводки и скачиваемые CSV рассчитываются из настоящих маршрутных рядов `GET /forecast`.

`forecast_origin` в существующем API — начало выбранного интервала и ограничитель длины запроса. Он не означает переобучение модели. Историческая отсечка артефакта — 31.10.2025; это указано в карточке модели. Отчёт нового архива содержит score 0.90461 на платформе для файла с 10 маршрутами. Score без маршрута 5 для нового файла не опубликован. Для ML-гибрида опубликованы временные бэктесты: октябрь (WAPE 8.8193%, score 0.9118) и сентябрь–октябрь (WAPE 17.9045%, score 0.821), а также WAPE по каждому из девяти маршрутов. Отдельный временной бэктест **финального** ансамбля не опубликован. Поэтому статус карточки остаётся `validation_pending`, без выдуманного WAPE финала.

Локальный `.env` и шаблон `.env.example` выбирают `PREDICTOR_FACTORY=app.predictors.tram_final:build_predictor`. При смене провайдера сервер нужно перезапустить. Docker Compose использует этот же провайдер по умолчанию и копирует CSV в образ. Для проверки:

```powershell
backend\.venv\Scripts\python.exe -m pytest -q backend/tests/test_tram_final.py
```
