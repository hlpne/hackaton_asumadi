# Интеграция `tram_final/tram_final`

Модель прогнозирует **успешные валидации за час по всему маршруту**. Это не занятость вагона и не прогноз по остановке. Backend читает исходный `tram_final/tram_final/outputs/submission_final.csv` (SHA-256 `05d73ac9bff3364cd1df815c3a3bd5d4a25cdcd2d2711db9e7a5ae7e9778d901`) без промежуточной копии. API загружает его один раз при запуске и выдаёт маршрутный ряд без округления или пересчёта. Месячный экран суммирует 24 часовых значения для каждого дня.

Папка содержит 15 бустеров объёма, один бустер профиля, исходники конвейера и предрассчитанные выходы. Агрегированная история `labels_day_train.csv` и `labels_day_test.csv` находится в `data/labels/`. Итоговый прогноз за ноябрь–декабрь 2025 включает математический ансамбль, сезонную поправку и обработку 1 ноября. Поэтому backend использует **проверенный конечный результат всего конвейера** для этих дат. Новый контейнер `model` использует сохранённые 16 LightGBM-моделей и исторические метки для расчёта других дат.

Покрытие финального ансамбля: 01.11–31.12.2025. Экстраполяция потоковой ML-модели доступна с 01.01.2026 до 31.12.2027. Оба варианта поддерживают маршруты 1, 7, 11, 12, 17, 25, 26, 28, 50. В исходном CSV есть маршрут 5, но он исключён из проекта по требованию команды: для него нет обучающей цели в этой версии сайта. В интерфейсе доступны день и месяц; годовой режим пока недоступен. Для `GET /forecast` без `stop_id` и `direction_id` API возвращает `value_unit=validations`, `aggregation=sum`, `is_mock=false` и `model_version=tram-final-2025-0.90461` либо `tram-stream-extrapolation-2025-10` по дате. Маршрут 5 и даты вне покрытия возвращают 503.

Для будущих дат сервис применяет тот же потоковый режим `anchor`, что указан в `artifacts/manifest.json`: 15 сохранённых бустеров объёма и один бустер часового профиля. Признаки-лаги основаны только на фактической истории до 31.10.2025. Дополнительные годы расширены приближённым календарём фиксированных праздников и выходных; погода не используется в сохранённых конфигурациях бустеров. **Это не финальный ансамбль 40/60** и не переобучение при выборе даты. Для 2026–2027 годов нет доступных фактических валидаций или бэктеста, поэтому score 0.90461 к этим прогнозам не относится. Для контрольной даты 15.12.2025 новый сервис воспроизводит все 24 значения маршрута 1 из `submission_ml_stream_anchor.csv`.

`GET /forecast/map` по остановкам остаётся техническим источником точек карты и сохраняет `is_mock=true`, `value_unit=demo_index`; его численные значения интерфейс не показывает. Остановки представлены по имени и месту, линии окрашены по маршруту. Рейтинг сети, сводки и скачиваемые CSV рассчитываются из настоящих маршрутных рядов `GET /forecast`.

`forecast_origin` в существующем API — начало выбранного интервала и ограничитель длины запроса. Он не означает переобучение модели. Историческая отсечка артефакта — 31.10.2025; это указано в карточке модели. Отчёт нового архива содержит score 0.90461 на платформе для файла с 10 маршрутами. Score без маршрута 5 для нового файла не опубликован. Для ML-гибрида опубликованы временные бэктесты: октябрь (WAPE 8.8193%, score 0.9118) и сентябрь–октябрь (WAPE 17.9045%, score 0.821), а также WAPE по каждому из девяти маршрутов. Отдельный временной бэктест **финального** ансамбля не опубликован. Поэтому статус карточки остаётся `validation_pending`, без выдуманного WAPE финала.

Локальный `.env` и шаблон `.env.example` выбирают `PREDICTOR_FACTORY=app.predictors.tram_final:build_predictor`. При смене провайдера сервер нужно перезапустить. Docker Compose копирует в backend-образ итоговый CSV, а в отдельный образ `model` — агрегированные метки, исходный код признаков и бустеры. Сырые файлы валидаций не копируются. Модельный сервис доступен backend по внутреннему адресу `http://model:8080`, наружу порт не публикуется. Для проверки:

```powershell
backend\.venv\Scripts\python.exe -m pytest -q backend/tests/test_tram_final.py
```
