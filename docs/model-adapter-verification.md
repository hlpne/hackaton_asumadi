HTTP-проверка запускалась на `127.0.0.1:18007` через
`backend/scripts/check_model_api.py --base-url http://127.0.0.1:18007 --expected-model ...`.
Для каждого provider проверены day (24 точки), февраль 2028 (29 точек), year
(12 точек), равенство первой точки ряда географическому срезу и ранжирование Top-N.
После проверок серверы остановлены. Пользовательская БД не использовалась.

В тестах дополнительно проверены однократная загрузка pickle, метаданные реального
provider, timezone, ошибки файлов/схемы признаков, неправильная длина/форма выхода,
NaN/Infinity/отрицательные значения и отсутствие автоматического fallback backend.

Среда: Linux x86_64, Python 3.12, CatBoost 1.2.8, NumPy 2.5.3,
Pandas 3.0.6, SciPy 1.18.1. Прямые зависимости backend сохранены из main.
Два предупреждения deprecation относятся к существующей связке
FastAPI/Starlette/httpx и AnyIO; тесты завершились без ошибок.

## Что эта проверка не подтверждает

- Docker недоступен в среде. Новые Docker build arg и Compose override подготовлены,
  но фактическая сборка образа и запуск контейнера с CatBoost здесь не выполнены.
- Команды PowerShell написаны для команды; их выполнение на Windows здесь
  не проверялось. Проверены эквивалентные команды Python/Uvicorn на Linux.
- Это проверка интерфейса модели, а не качества прогнозирования. Сгенерированная
  CatBoost использует синтетические метки, `is_mock=true`, `demo_index`.
- Frontend не дорабатывался и визуально повторно не тестировался.
  Его локальный fallback и другие замечания относятся к следующей задаче.
- Известная проблема snapshot с устаревшим origin (500 вместо 422)
  не входит в этот патч; зафиксирована в плане следующего этапа.
