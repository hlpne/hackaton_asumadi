# Проверка стартового проекта

Дата: 11 сентября 2026 года. Область: задачи `[P0][ARCH]` и `[P0][DEV]`.

Это отчёт исходного каркаса. Доработка и отдельные проверки DB-задачи описаны
в [db-verification.md](db-verification.md); команды приёмки — в [db.md](db.md).

## Выполненные проверки

| Проверка | Результат |
|---|---|
| `python -m pytest -q` в `backend/` | 29 проверок прошли |
| `npm run build` в `frontend/` | Проверка TypeScript и production-сборка Vite прошли |
| Запуск Uvicorn на 8000 и Vite на 5173 отдельными процессами | Оба процесса запустились; приложение и исходные frontend-модули доступны по HTTP |
| HTTP через Vite `/api/routes` и `/api/forecast` | Справочник и прогноз получены от работающего backend |
| `/api/docs` и `/api/openapi.json` | Документация и схема доступны через тот же прокси |
| Замена `PREDICTOR_FACTORY` с `mock` на `constant` | После перезапуска только backend тот же процесс frontend получил 42 и null-границы |
| Compose | YAML разобран, имена трёх сервисов и локальные пути bind mount проверены |
| Документация контракта | Примеры JSON, JSON Schema и OpenAPI сверены с действующим кодом |
| `git bundle verify` и `git clone` из bundle | Переносимый репозиторий корректен, ветка `main` клонируется |

Автоматические проверки охватывают день, месяц, год и февраль високосного года; границы `[from, to)`; часовые пояса; направление; принадлежность остановки маршруту; ошибки запросов; отклонение неполной или некорректной выдачи модели; отсутствие скрытой подмены отказавшей модели mock-провайдером.

Заменяемость дополнительно проверена через провайдер-заглушку с `is_mock: false` и другой единицей показателя. Этот тест не является реальной ML-моделью.

## Среда

Python 3.12.14, Node.js 24.19.0, npm 11.9.0. Установленные версии зафиксированы в `backend/requirements*.txt` и `frontend/package-lock.json`: FastAPI 0.141.1, Pydantic 2.13.5, React 19.3.0, Vite 7.3.6, TypeScript 5.9.3.

Тесты завершились с двумя предупреждениями о deprecated API в сторонних библиотеках Starlette/httpx/AnyIO; ошибок тестирования нет.

## Пределы проверки

- Docker и PostgreSQL-сервер в среде подготовки отсутствуют. Docker-образы не собирались, контейнеры не запускались, SQL и `PostgresCatalog` на живой PostgreSQL не проверялись. Статическая проверка YAML этого не заменяет.
- Реальный локальный HTTP-сценарий проверен без браузерной автоматизации. Визуальная проверка браузера и кроссбраузерное тестирование не выполнялись.
- Команды Windows подготовлены в README, но запуск выполнен в Linux.
- Датасета и реальной модели нет; качество прогноза, нагрузочное поведение на миллионах событий и точность интервалов не оценивались.
- Git-репозиторий передаётся переносимым bundle. Облачный remote не создаётся, карточки Trello не изменяются.
