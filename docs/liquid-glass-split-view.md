# Обновление интерфейса мониторинга и сети

## Что изменено

- Легенда загрузки находится по центру нижней части карты. Правая панель стала шире.
- Период и горизонт прогноза открываются кнопкой с пиктограммой у левого края блока параметров. Закрытие: крестик, Esc или нажатие вне панели. Календарь появляется непосредственно под полем даты.
- Выбор маршрута и остановки в разделе «Сеть» использует те же барабанные списки, что и мониторинг. Выбранный маршрут выделяется на схеме, остановка отмечается на карте.
- Колесо мыши в открытом барабане делает один шаг с защитой от повторов одного жеста. Сенсорная прокрутка списка и клавиши со стрелками остаются доступны.
- Раздел «Сеть» использует всю высоту рабочего окна, аналогично мониторингу. Правые панели обеих страниц немного уже, поля остановок занимают полную ширину.
- Карта передаёт тёмную или светлую тему непосредственно компоненту YMap, чтобы встроенные элементы и логотип карты получали правильные цвета.
- Новое окно карты создаётся перетаскиванием любого из четырёх краёв карты к центру минимум на 48 пикселей. Край подсвечивается при наведении, при достаточном перетаскивании появляется предварительный просмотр. Отпускание создаёт окно рядом с выбранным краем.
- Получившаяся граница служит разделителем для изменения размеров указателем и клавишами со стрелками. Можно создать до четырёх окон; закрытие окна схлопывает его локальную границу. Раскладка и размеры сохраняются в URL.
- В каждом окне мониторинга доступна полная аналитика маршрута: показатели, график, сводка и список остановок, а не только настройки периода.
- В разделе «Сеть» тот же жест от края создаёт соседнюю карту с независимыми параметрами и аналитикой. Раскладка сети сохраняется отдельно от раскладки мониторинга.
- Раскрытые барабаны отображаются поверх прокручиваемых панелей, не обрезая названия. Барабанные списки используются также для «Все остановки» и рейтинга маршрутов/остановок; после прокрутки выбранный элемент можно явно открыть кнопкой.

Для клавиатуры края карты доступны по Tab; Enter или пробел создаёт соседнее окно. В каждом окне кнопки справа разворачивают выбранное окно и закрывают его.

## Проверка

```bash
cd frontend
npm ci
npm test
npm run build
```

Для проверки карты Яндекса в браузере нужен ключ `VITE_YANDEX_MAPS_API_KEY` в локальной среде проекта. Без ключа доступна схема маршрутов; встроенный логотип Яндекса в этом режиме не показывается.
