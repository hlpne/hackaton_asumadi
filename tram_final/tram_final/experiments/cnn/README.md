# Эксперимент: свёрточная нейросеть (PyTorch) — в финал не вошла

`cnn.py` — CNN для прогноза маршрут × день × час, режим прогноза тот же, что у LightGBM: отсечка → прогноз на 61 день без фактов.

- **Вход** — «картинка» последних 28 дней × 24 часа. Каналы: посадки / уровень маршрута, тип каждого дня (будни / суббота / воскресенье-праздник), флаг ограничений 7/50.
- **Признаки целевого дня** — тип дня, день недели, праздник, предпраздничный день, рабочая суббота, школьные каникулы, длина и позиция блока выходных, ограничение, горизонт, маршрут.
- **Архитектура**: Conv2d 3×3 → Conv2d 3×3 → свёртка по всем 28 дням → вместе с признаками дня и базовым профилем → Conv1d по часам.
- **Выход** — 24 часа = уровень × (B + поправка). B — профиль последних дней того же типа.
- **Обучение**: L1 в посадках (≈ WAPE), вес по давности (полураспад 45 дней), 10 эпох, AdamW + OneCycle; около 117 тыс. примеров (отсечка × горизонт × маршрут).

Запуск: `python cnn.py 2025-09-30 2025-10-31` — обучение до 30.09, прогноз октября.

## Бэктест (обучение только до отсечки)

| Отсечка → прогноз | CNN | LightGBM | 0,8·LGB + 0,2·CNN | Гибрид (LGB) | Гибрид (0,8·LGB + 0,2·CNN) |
|---|---|---|---|---|---|
| 30.09 → октябрь | 0.9030 | 0.9116 | **0.9126** | 0.9122 | **0.9127** |
| 31.08 → сентябрь–октябрь | 0.8109 | **0.8366** | 0.8329 | **0.8215** | 0.8188 |
| 31.07 → август–сентябрь | **0.7904** | 0.7836 | 0.7871 | 0.7947 | **0.7955** |

«Гибрид» здесь — сумма за день 0,5 × модель + 0,5 × медиана 4 недель, профиль часов берётся из модели, как в финале.

Базовый профиль B без нейросети даёт 0.8994 / 0.8035 / 0.7826.

## Вывод

Отдельно CNN слабее LightGBM на двух отрезках из трёх. Смесь помогает на октябре и августе–сентябре (+0.0005…+0.001), но на сентябре–октябре хуже на 0.003. Там смена режима: с 06.09 ограничения на маршрутах 7 и 50. В среднем по трём отрезкам выигрыша нет, поэтому CNN в финальный ансамбль не добавлена. Иначе её вес пришлось бы подбирать по скору на платформе.
